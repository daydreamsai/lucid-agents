| Concern                                               | Owning extension/package                              |
| ----------------------------------------------------- | ----------------------------------------------------- |
| Metadata and entrypoints                              | `@lucid-agents/core`                                  |
| HTTP routes, authorization orchestration, idempotency | `@lucid-agents/http`                                  |
| x402, SIWX, payment policy/storage                    | `@lucid-agents/payments`                              |
| MPP challenges and credentials                        | `@lucid-agents/mpp`                                   |
| Agent/developer wallets                               | `@lucid-agents/wallet`                                |
| Agent Cards, client, tasks                            | `@lucid-agents/a2a`                                   |
| ERC-8004 initialization                               | `@lucid-agents/identity`                              |
| Framework binding                                     | Hono, Express, TanStack, or generated Next.js adapter |

Compose configuration where the concern is owned. The core must not translate
or wrap an extension runtime when the extension already exposes the required
public contract.
