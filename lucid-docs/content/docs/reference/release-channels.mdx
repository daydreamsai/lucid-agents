| Badge          | Contract                                                                |
| -------------- | ----------------------------------------------------------------------- |
| Stable         | Publicly installable npm surface verified from a clean project          |
| Next           | Current repository surface; packages may be unpublished or ahead of npm |
| Experimental   | Available but subject to API or support changes                         |
| Deprecated     | Historical migration context only                                       |
| Hosted product | Separately operated service with its own availability                   |

As of the verification date, core, payments, CLI, identity, and API SDK are
Stable at 2.5.0, while their corresponding repository manifests are 3.0.0.
MPP and catalog are repository-only. Other packages have independent versions;
read each page's badge rather than assuming the core version applies to every
package.

Do not mix Stable and Next imports opportunistically. Use the dependency set
generated by one channel, keep a lockfile, and test the assembled application.
